# 终端界面

在交互终端运行 `mihomo-py` 或 `mihomo-py tui`。建议至少 80×24，支持鼠标及 Tab / Shift-Tab 导航。界面采用石墨色背景与低饱和强调色；小终端自动压缩间距，大终端扩展内容空间。支持 `NO_COLOR`，状态同时用文字和标识区分。

打开界面不会自动启动内核，退出界面会保留运行中的内核。后台每 2 秒刷新，网络请求和内核操作在线程中执行；保存或操作内核期间需等待完成后退出。

## 语言

首次打开时，界面按系统语言选择中文或英文；无法识别的系统语言回退中文。顶部「语言」按钮可随时选择「跟随系统」「中文」或「English」，选择会保存到当前数据目录的 `state.json`，下次打开继续使用。默认的跟随系统设置不会修改系统语言。

后台操作期间仍可浏览现有列表、切页、搜索、选择代理组、暂停日志，以及打开和关闭帮助或详情。修改类按钮及执行中的表单会锁定，避免并发操作；后台操作完成后刷新数据。

帮助、详情和表单弹窗支持鼠标左键点击弹窗外部关闭，等同于按 Esc；未提交的表单不会保存。点击弹窗内容、边框或下拉选项不会关闭弹窗。执行中的表单需等待操作完成后关闭；多层弹窗只关闭最上层，关闭后恢复原来的焦点。

## 状态与订阅

顶部展示内核状态、已选 / 运行订阅、完整代理监听地址与端口和路由模式。高亮行是当前浏览项，`●` 表示已选订阅或生效节点，两者不一定相同。

添加 URL 或本地 YAML 后，新订阅会被高亮并获得焦点，按 Enter 使用；内核停止时，使用成功后焦点移到「启动」，可继续按 Enter 启动。添加和使用不会自动启动内核。已有订阅时，打开界面优先聚焦订阅列表。支持更新订阅、更换来源和确认删除。运行中的订阅不可删除，删除弹窗默认聚焦「取消」。

订阅列表单击只选择；双击订阅项、按 Enter 或点击「使用」执行应用。运行中切换其他订阅时，按钮显示「使用并重启」，操作会短暂中断连接。更新正在使用的订阅时显示「更新并应用」；更新或更换来源造成配置变化时会重启，按钮提示及编辑表单会说明这一点。

列表随终端宽度调整，长内容以省略号收尾；按 `i` 查看当前行完整信息。列表与详情里的远程来源均脱敏；更换来源时会在编辑弹窗预填完整原值，便于检查和修改。

表单中 Enter 跳到下一字段，最后一个文本字段按 Enter 提交。必填项、监听地址与端口校验失败后保留输入并定位字段。设置中的路由模式从 `rule / global / direct` 选择，代理监听 IPv4 地址默认为 `127.0.0.1`，可设为 `0.0.0.0` 监听所有接口；管理 / Web IPv4 地址独立设置，默认 `0.0.0.0`；安装 `[web]` 后，「Web 面板」显示地址和登录密钥。运行中应用设置会重启内核。

添加、更新和更换订阅来源时，显示读取订阅、准备地理数据、配置校验、应用保存的进度。下载超时与校验超时有不同提示；失败不会保存新订阅或覆盖旧配置。错误摘要显示在底部或弹窗内，「错误详情」或 F8 可查看操作名、异常类别与安全的具体原因；IO 错误带有系统错误码时，还展示错误码及系统原因。详情不展示未经脱敏的异常文本，内核原始诊断继续保存在本地 `validation.log`。

## 节点

启动内核后选择代理组，按 `/` 聚焦名称搜索；搜索框内 Esc 清空搜索并返回列表。选中节点按 Enter 或点击「切换节点」；仅手动组（Selector）可切换，自动组可查看和测速。

自动刷新保留当前行和滚动位置；切页及关闭弹窗后恢复焦点。节点切换立即生效，无需重启，并按订阅缓存，在内核重启后恢复。若从旧版升级且内核仍在运行，请先重启一次，使 `profile.store-selected` 生效。

「测试延迟」只测试当前选中的一个节点，明确显示待测、测试中、成功结果或失败。默认目标为 `https://www.gstatic.com/generate_204`，可在节点页修改。请求经过所选节点，测量 HTTP 延迟而非下载带宽；失败可更换目标后重试，按 `i` 查看该节点的测速错误。

## 日志

显示最近 200 行，默认跟随末尾。向上滚动或点击「暂停」后，当前阅读窗口冻结；后台有新内容时显示「有更新」。点击「继续」或在日志区域按 End，加载最新内容并恢复跟随。

日志可能包含订阅内部地址，分享日志前请检查内容。

## 文本选择与复制

在详情、帮助、日志或状态文本上按住鼠标左键拖选，再按 `Ctrl+C` 或 `Ctrl+Shift+C` 复制；仅选中不会改动剪贴板，复制后清除文本选区。输入框中选中的文字也支持这两个快捷键。没有选区时会提示操作方法，复制键始终不会退出界面或关闭弹窗。

订阅与节点表格保留单击选择、双击使用订阅等操作；需要复制完整行内容时按 `i` 打开详情后拖选。

与 `dt view` 一样，复制同时发送终端 OSC52 并尝试可用的本地 `wl-copy` / `xclip` / `xsel`；tmux 下还写入 paste buffer。SSH 下依赖本机终端允许 OSC52 写剪贴板；tmux 需开启 `set -g allow-passthrough on`。若 `Ctrl+Shift+C` 由终端自身处理，则仍使用终端的复制行为；传给 TUI 时执行选区复制。

## 快捷键

| 按键 | 行为 |
|---|---|
| `1` / `2` / `3` | 切换订阅 / 节点 / 日志 |
| Tab / Shift-Tab | 下一个 / 上一个控件 |
| ↑ / ↓ | 选择列表行 |
| Enter | 使用订阅、切换手动组节点或操作当前控件 |
| `/` | 在节点页聚焦搜索 |
| Esc | 清空节点搜索，或关闭弹窗 |
| `i` | 查看当前订阅或节点的完整信息 |
| `?` | 快捷键帮助 |
| Ctrl-R | 刷新 |
| Ctrl-A | 添加订阅 |
| Ctrl-C / Ctrl-Shift-C | 复制选中的文本，没有选区时提示 |
| F8 | 展开完整错误 |
| End | 在日志区域恢复跟随 |
| `q` / Ctrl-Q | 退出界面，保留内核 |

输入框保留原生编辑快捷键，普通字符不会触发切页等全局动作；代理组下拉展开时可直接输入检索。弹窗内不会切换主页面。
